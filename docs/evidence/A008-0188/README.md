Den tidigare CURRENT_TASK hade en implementationssammanfattning men ofyllda
Goal/DoD-fält. A008-0188 ersätter den som aktivt arbete på ägarens uttryckliga
begäran. Kopian innebär ingen avslutad implementation. Fortsatt runtime-arbete
måste chartras mot den nya grunden.

Manifestet anger originalväg, arkivväg och hash för de fyra huvuddokumenten och
de fem ADR:er som flyttades från aktiv uppsättning. Äldre redan arkiverade
ADR:er ligger kvar. Alla gamla ADR:er är historiska oberoende av deras interna
Status-etiketter; aktuell auktoritet finns i [ADR-registret](../../adr/README.md).
