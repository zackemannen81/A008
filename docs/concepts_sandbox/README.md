# Concepts Sandbox

Discoverability: index. Every top-level member is listed below.
Member state: Markdown concepts retain their own `Status:` where present; assets and directories are indexed by type, not given an approval state.

This directory holds non-authoritative exploration, imported material and
assets. Some drafts overlap behavior now present in A008; that does not make
the draft authoritative or prove full acceptance. Product direction belongs in
`PROJECT_BRIEF.md`, implemented behavior in `SYSTEMDOC.md`, and observed
verification in `CURRENT_STATUS.md` plus the task handoffs/archives. A concept
becomes actionable only through an accepted decision or reviewed task.
