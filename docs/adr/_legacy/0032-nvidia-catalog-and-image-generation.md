# ADR 0032 — NVIDIA catalog, image generation and provider settings

Status: Accepted
Date: 2026-09-08
Task: A008-0071
Amends: ADR 0019 D3/D4 (host may call NVIDIA catalog and image endpoints).
The inherited ADR 0020 D6 statement that `ChatMessage.content` remains a string is superseded by [ADR 0045](0045-multimodal-conversation-content.md).

## Decision

The GUI can browse NVIDIA Build models available to the process API key
(`GET https://integrate.api.nvidia.com/v1/models`) and add selected chat models
to a user catalog stored outside the repository (`~/.a008/catalog.json`, or
`A008_CATALOG_PATH`). Added models merge into `GET /v1/models` with conservative
unverified generation controls. They are not claimed as vendor-sample-verified.

Image generation is a separate host route, `POST /v1/images`, not a chat
completion. Default model is `black-forest-labs/flux.1-schnell` at
`https://ai.api.nvidia.com/v1/genai/black-forest-labs/flux.1-schnell`. The
renderer never holds the credential. Generated bytes are stored in the existing
source blob store and shown in the transcript by locator.

Provider settings (image model, image endpoint, optional chat endpoint, API key)
are edited in Parameters. The API key is write-only: `POST /v1/secrets` stores it
under `~/.a008/secrets.json` (or `A008_SECRETS_PATH`) with owner-only access.
`GET` reports only whether a key is configured. Chat completions still run in
ACP; a new key applies to chat after reconnect. Image and catalog calls on the
host can use the saved key immediately.

NVIDIA Build "Free Endpoint" means a hosted NIM callable with `NVIDIA_API_KEY`
against NVIDIA's cloud, typically against a limited credit quota. It is not an
unlimited zero-cost guarantee. FLUX.1-schnell is Apache-2.0 and is the default
image route; whether a given account still has quota is an operator fact.

## Consequences

The host now performs two NVIDIA HTTPS calls (catalog list, image generate) with
the process or secrets-file key. The renderer still never sees a credential.
Adding an unverified chat model can fail at the provider; A008 does not invent
sampling schema for it. Image turns are GUI transcript attachments, not a change
to `ChatMessage.content`.
