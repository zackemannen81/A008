## Definition of done

`npm run gui-host` (or equivalent) serves the GUI, opens an ACP session, streams
thought and answer from a fake transport, runs `/shell` in the host, and never
puts `NVIDIA_API_KEY` on the WebSocket.

## Operator integration beyond the child scopes

Two shell-level files sit outside every child write scope and were changed by
the operator when the children were integrated:

- `gui/vite.config.ts` — the `/v1` dev proxy gained `ws: true`. The session
  client resolves its socket from `location.host`, so under `vite dev` the
  upgrade goes through this proxy; without the flag the ACP bridge was
  unreachable in development. The production single-origin path was unaffected.
- `package.json` — added `npm run gui`, which builds `gui/` and then starts the
  host, so one command serves the product GUI from one origin.
