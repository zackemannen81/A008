## Operator note

The delegated run built the config validation, the runtime method and the params
parser, then stopped at the session limit before the agent handler, the
`server.ts` registration and any tests. The operator added those three.

Two corrections were needed while writing the gates:

1. **The lexical containment gate was untested.** Disabling it changed nothing,
   because every traversal case was also caught by the realpath check. A case
   whose traversal target does not exist now separates them: the lexical gate
   rejects on the locator's shape, while realpath would instead complain the
   file does not resolve, so asserting the message identifies which gate fired.
2. **The link-escape case skipped itself.** A file symlink needs elevation on
   Windows, so the realpath gate — the only one that catches a link inside the
   store pointing out of it — was going unproven on this machine. Rewritten to
   use a directory junction, which needs no elevation, and it now runs.

## Risks

1. **Nothing yet composes an image extractor.** The runtime's default registry
   is text-only, so an uploaded image reaches `unsupported_media_type` until a
   vision model is configured and a describer is composed. That is ADR 0020 D8
   and needs an owner decision, not code.
2. **`A008_SOURCE_STORE_PATH` validation is duplicated** between here and
   `src/gui-host/source-store.ts`, because the two were sibling write scopes in
   this wave. The shapes agree; collapsing them is a tidy-up.
3. **One source is one utterance.** A large document becomes a single
   `Utterance` whose kind `classifySpeech()` guesses. Recorded in
   `docs/backlog/document-ingest-granularity.md`; it should be settled before
   real documents are ingested at volume.
