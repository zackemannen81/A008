## Delivered

The fourth runtime-context task is chartered, reviewed, frozen and implemented.
Platform SQLite v6 stores a checkpoint-bound recovery supplement and durable
effect fence. The existing coordinator can continue an unfinished GUI run after
process loss when its last completed boundary and workspace evidence remain
valid. Recovery consumes eligibility with a new lease and keeps durable
run/session/workspace and runtime turn identity while replacing instance/PID.

Recent raw context, source refs, cumulative tool budget, duplicate IDs and exact
selected-route measurement survive replacement. Stored tools are never replayed.
Public tool snapshots preserve the prior process's completed results. Private
provider reasoning is omitted from durable recovery data. Normal memory
retrieval and final post-output intake keep their existing owners.

Changed/unverifiable workspace evidence or a post-checkpoint effect fence leaves
`needs_reconciliation` with an explicit uncertainty reason. Missing workspace
uses `WORKSPACE_MISSING`. Cancellation, explicit process stop, graceful host
shutdown, stale leases and newer accepted work cannot silently resume old work.
An invalid checkpoint cannot create replay authority; historical rows survive.

Integration exposed missing measurement forwarding in direct dispatch, the
runtime timeout wrapper and debug tracing. These now forward the existing
provider capability without inventing a budget or route. Newly compacted
sources are bound incrementally; prior durable provenance is reused.

## Limits and handoff

- Recovery is opt-in through the existing continuation pressure settings.
- Exactly measured routes are required. The current default embedded-ACME
  adapter remains unmeasured and fails closed when pressure is enabled; this
  task did not add a new provider route or fallback.
- Local read/list/create/edit tools expose artifact paths. Opaque Git/terminal/
  external effects, symlinks/submodules or scan limits make evidence unverifiable.
- Evidence scans are capped at 10,000 paths / 64 MiB and do not atomically lock
  out subsequent external writes. Old checkpoints without supplements remain
  readable but cannot resume.
- No full repository-wide `npm test`, live-provider call, deployment, push or
  remote merge was performed. Relevant local integration and full GUI suites
  cover this local recovery change; provider wire behavior beyond those
  fixtures is not claimed.
