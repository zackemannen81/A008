## Problem and result

The default product runtime sent all tool schemas and, with 0/0 pressure defaults,
accumulated completed raw tool rounds. Worker/extractor serialization also diverged:
worker IDs had already been removed in aefe303, but extractor and serialized retrieval
traces retained IDs/addresses/full values despite ADR 0061. Historical fallback labels
could omit their historical qualification. These are A008 context-construction issues,
independent of a provider outage; this work does not establish which installed build
produced the owner's observed log.

CLI/ACP/GUI now use a compact catalog and demand-loaded exact schemas, incremental
completed-work reduction and the latest complete raw round. Selection has no external
effect but has a terminal evidence receipt, counts against the existing tool-call
budget and preserves durable checkpoint validation. It grants no execution permission.
New processes rediscover schemas; consumed call IDs and effect fences remain intact.

Worker/extractor/traces share label plus conditional history/provenance. Extractor
positions resolve internally before unchanged reinforcement/state-update validation.
Clean current-message strings remain separate from bounded currentScope excerpts of
up to two turns. No memory store, retrieval ranking, reinforcement or decay changes.
Workspace/revision/uncertainty qualifiers remain where necessary for interpretation.

Embedded native Responses retains exact original call and opaque reasoning items
beside their matching outputs. It supplies manual context with store=false and
encrypted reasoning continuation instead of chaining server-side history. The same
augmentation is measured and sent. Reducers do not receive opaque reasoning tokens.
Reference: [official Responses reasoning continuation guidance](https://developers.openai.com/api/docs/guides/reasoning#keeping-reasoning-items-in-context).

## Limits and integration

This is a source/runtime change, not an installer rollout. An already-running host
or packaged desktop runtime must be rebuilt/restarted through its normal deployment
path to consume it. No live token-cost/latency improvement is claimed. Incremental
reduction adds bounded model work; the 7 kB measurements describe the fixture only.

0/0 still disables durable pressure/checkpoint handling; baseline projection now
compacts independently. It does not add recovery authority to routes without it.
Unsafe/unknown external effects still require reconciliation. Summary statements
remain untrusted run data with validated source coverage, not newly verified facts.

0213 already has an immutable Complete archive on main; the stale active snapshot
was preserved when pausing and reconciled after this prerequisite passed. Its
workspace-lock/IPC/recovery gates also pass in the 110-round proof. 0214/0215 are
not absorbed. The integration operator appends JOURNAL on merge; no merge is claimed.
