## Result

The A008 diagnostic GUI implements every requested CLI interactive command and
alias against real runtime state. Parameters exposes model-specific stream,
sampling, reasoning and generated-token settings, with supported seed/stop
controls. Model switch creates a conversation; reset/undo update committed
history; exit releases the session. Saved memory remains unchanged by controls.
Chat/Memory/Tools work at mobile width and the parameter dialog supports native
modal keyboard focus. No external frontend source was adopted.

## Boundaries and integration

- No live provider, private memory, `.env.local`, credential or external
  client was used. All browser/provider messages and screenshots are synthetic.
- Test host/provider/tabs stopped; temporary viewport reset. Temporary evidence
  helpers and raw synthetic payloads remain outside the repository.
- Existing untracked `docs/concepts_sandbox/gui/` is owner material and untouched.
- `maxTokens` is generated reasoning + answer per call, excluding input tokens,
  semantic-memory processing and spend. The protocol is explicit about this.
- Parameters/history are session-local. Changing model or reconnecting restores
  runtime defaults. Kimi has no reasoning-off mode; Laguna has no exposed
  reasoning control. Unsupported fields cannot be submitted as active settings.
- Restart the host with the built source before testing the new ACP method.
  The current GUI can still connect to an older ACP composition; controls then
  report that the runtime needs upgrading.
