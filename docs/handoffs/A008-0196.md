# A008-0196 — Bounded intra-turn context and continuation state

Completed 2026-09-29 on task branch based on `ae118e1`.

## Outcome

A008 now has an opt-in, run-local continuation layer for long tool loops without
changing inter-turn semantic memory.

- `src/core/chat-continuation.ts` owns the versioned
  `a008_run_continuation_state_v1` contract.
- Continuation state separates verified facts, hypotheses and completed actions.
  Every entry must cite retained raw interaction IDs.
- `ChatTools.continuation` supplies a caller-owned reducer, recent raw-tail size
  and maximum serialized UTF-8 state size.
- `ChatSession` offers only completed assistant/tool rounds older than the raw
  tail to the reducer. In-flight or partially failed batches are never eligible.
- Reducer output is validated for schema, run binding, unique entry IDs,
  resolvable provenance, cumulative source coverage and byte size before it can
  replace projected old interactions.
- The reducer receives a detached full previous continuation state including
  `runId`; a later reduction cannot silently forget sources already represented
  by the previous valid state.
- Provider chronology is preserved as current user request → temporary
  continuation state → recent raw assistant/tool rounds. Compacted tool output
  is never projected before the user request that caused it.
- Canonical raw interactions remain retained for the active run. Without an
  explicit continuation policy, existing full wire-history behavior is
  unchanged.

The task also registered two already tracked tests that were missing from the
base `test:core` list (`file-routes.test.ts` and `skill-library.test.ts`) so
the frozen repository-membership gate is truthful. This changes test coverage

## Boundaries

A008-0196 deliberately does **not** provide:

- a semantic/LLM continuation reducer;
- automatic context-budget measurement or trigger thresholds;
- persisted continuation checkpoints;
- automatic same-run context rebuild after budget pressure;
- process-loss/restart recovery;
- any change to A008 semantic-memory retrieval, extraction, state or lifecycle.

Those remain later program slices. A008-0197 may build durable continuation
checkpoints on this base after its own charter is frozen and revalidated.
