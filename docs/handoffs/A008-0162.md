## Public surface for dependent work

Import from `@a008/protocol`:

- Resource and HTTP schemas: `platformV3ConversationSchema`,
  `platformV3ConversationMessageSchema`, `platformV3RunSchema`,
  `platformV3CommandReceiptSchema`, `platformV3EventSchema`,
  `platformV3InfoSchema`, request/response schemas, and
  `platformV3ErrorResponseSchema`.
- Generation/metadata: `platformV3JsonSchemas()` and
  `platformV3OpenApiDocument()`.
- All new inferred types use the `PlatformV3*` prefix; new schemas/functions
  use `platformV3*`.

The explicit protocol boundary is strict V3-owned envelopes, opaque nonempty
IDs up to 256 characters, safe nonnegative revisions/cursors/timestamps,
bounded title/model/text/event page values, exact first-slice enums, and no
authority fields on mutation bodies. Conversation message content uses the
existing `chatContentSchema` unchanged; its nested content parsing behavior is
the accepted compatibility exception.

## Limitations and integration notes

This package is not a host endpoint, persistence layer, authenticated scope
resolver, idempotency/lease implementation, execution loop, or V3 availability
claim. Host HTTP status mapping remains frozen with its adapter. The store worker
may use independent internal representations aligned to this frozen vocabulary;
it must not import runtime/provider/memory behavior through this package.
