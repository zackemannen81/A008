# A008-0191 handoff

Completed on 2026-09-27 after resuming from published commits `ac0ce45` and
`6d1267b` when the previous Codex session hit its weekly limit.

## Delivered

- ADR 0055 durable project sessions now execute through replaceable per-session
  OS processes while session identity, history and workspace remain durable.
- The host owns project runtime and semantic memory; session workers communicate
  through typed local IPC and do not create competing project-memory owners.
- New durable project sessions keep isolated worktree/branch/base provenance;
  opening history alone starts no process, and a dead process is replaced with a
  new `instanceId`/PID on the next submitted command.
- Ordered durable activity supports snapshot-to-live reconnect without replaying
  accepted work. Navigation or client disconnect does not cancel execution.
- Unknown effects remain conservative: they are not replayed automatically and
  can be reviewed explicitly before dependent writes.
- Missing/discarded workspaces never fall back to the project checkout. A failed
  run now exposes the explicit `WORKSPACE_MISSING` error state end-to-end through
  runtime, protocol JSON schemas/OpenAPI and client validation.

## Completion finding

The final failing ADR 0055 integration test was caused by an incomplete error
contract, not by the session-process design. Coordinator emitted
`WORKSPACE_UNAVAILABLE` for a missing worktree, but that value was absent from the
V3 run error enum. The store correctly persisted a failed run; host response
validation then converted the otherwise valid result into a 500. The canonical
state is now `WORKSPACE_MISSING` and the lifecycle test passes.

A GUI gate also exposed one source-format-sensitive assertion for the existing
File/Edit/View/Help menu. The menu/actions were intact; only the array formatting
changed. The assertion now tolerates whitespace without changing product UI.

## Remaining boundaries

- Legacy V1/V2/ACP/standalone histories are not silently migrated into durable
  project sessions.
- Legacy `legacy-unbound` durable sessions remain history-readable but not
  executable until explicitly migrated to a worktree.
- Durable prompt input parity is not complete across every older adapter; image
  attachments/undo/generation controls remain compatibility-surface concerns.
- No automatic Git merge/publish/workspace deletion was introduced.
- Session-process idle timeout remains intentionally unspecified by ADR 0055.
