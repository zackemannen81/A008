## Risks

1. **`extracted: false` is returned for both "no extractor" and "ACP
   unavailable".** The blob is stored either way, but the renderer cannot tell a
   permanently unsupported type from a transient failure. Once A008-0043 lands,
   the agent's named error should be surfaced through this route.
2. **The store grows without bound.** Nothing prunes blobs, and a re-uploaded
   file is deduplicated only when the bytes are identical.
3. **`resolveSourceStorePath` duplicates the validation shape of
   `resolvedSqlitePath`** rather than sharing it, because `src/runtime/` was a
   sibling's write scope during this wave. Worth collapsing later.
