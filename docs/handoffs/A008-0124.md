The live attempt exposed that the running sidecar/runtime composition had static provider/profile routing and was not the intended long-term A008 model-selection architecture. The owner then chose embedded in-process `@acme-engine/model-runtime` as the target before Step 4.

For that reason A008-0124 is recorded as **Superseded rather than Complete**. The remaining proof must be performed against the embedded execution architecture in its own bounded migration task; this handoff does not waive the original gate.

## Architecture follow-up

Preserve these A008-0124 invariants during the embedded-ACME migration:

- ACME owns execution mechanics, routing of the caller-selected provider/model, streaming/cancellation, execution evidence and provider adapters.
- Image attachments remain invocation-local; durable dialogue stays text-only.
- Unsupported image input fails before provider dispatch.
