# Handoff — A008-0153 Catalog-backed runtime model registry

Status: Complete
Date: 2026-09-22

## Root cause

The host/ACP model list merged shipped models with `~/.a008/catalog.json`, but
`LocalMemoryRuntime` still defaulted to the static `defaultModelRegistry`.
Imported models therefore appeared selectable while session parameter resolution
and runtime session creation failed with `Unknown model` before provider
execution.

## Delivered

- `ModelRegistry` now accepts a dynamic profile source.
- Shipped profiles retain precedence; dynamic profiles cannot overwrite them.
- `catalogBackedModelRegistry()` composes the current configured user catalog.
- `createAcpRuntime()` passes one catalog-backed registry to both
  `LocalMemoryRuntime` and `A008AcpAgent`.
- Dynamic catalog profiles are evaluated at lookup/list time, so a model added
  after runtime startup is available to a newly opened session without host
  restart.
- No model-specific hardcoding was added and provider routing is unchanged.
