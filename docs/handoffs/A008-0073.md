# A008-0073 handoff

Parameters → Provider now has a kie.ai section: write-only API key, chat/image
provider selects, and a curated market list. Chat uses OpenAI-compatible
completions in ACP; images use async Market jobs on the host. Video rows are
visible as **Not wired**.

Set `KIE_API_KEY` in `.env.local` or paste the key once in Parameters. Reconnect
the session after saving a new key. Default chat model is Gemini 3 Flash;
default image model is FLUX.2 Flex text-to-image.

Start with `npm run gui`. Connect. Open Parameters → Provider.
