# A008-0177 Handoff

Implemented the local persistent project-worktree lifecycle in `src/runtime/project-workspace-store.ts`.

`createWorktree` creates `a008/session-<suffix>` below a sibling `<project>-workspaces` directory. `status` exposes modified file count and commits ahead. `discard` fails closed for dirty worktrees and never merges, pushes or performs remote deletion. `keep` retains the owned workspace.

Focused test: `test/project-workspace-store.test.ts` uses a temporary Git repository. No provider calls or credentials are used.

Not delivered: protocol/GUI controls, agent-triggered session transition and binding the existing local ACP bridge to a selected worktree. Those need a follow-up that owns the typed V1 contract plus bridge selection lifecycle.
