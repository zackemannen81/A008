# A008-0071 handoff

Parameters → Provider browses NVIDIA Build models your API key can invoke and
can add them to `~/.a008/catalog.json`. Image generation is composer **+ → Image**
(describe the picture in the composer first). Default model is FLUX.1-schnell.
The API key field is write-only; chat needs reconnect after a new key.
Empty chat shows four start cards. **Files** in the header opens the tracked-file
tree.

Start with `npm run gui`. Connect. Open Parameters → Provider.

Verification: [evidence](../evidence/A008-0071_nvidia-catalog-images.md).
Decision: [ADR 0032](../adr/0032-nvidia-catalog-and-image-generation.md).
