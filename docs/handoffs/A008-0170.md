## Delivered

Global Instructions support exactly seven runtime-owned inline fields:

- `provider_model`
- `model_capabilities`
- `working_directory`
- `is_git_repo`
- `platform`
- `os_version`
- `today_date`

Whitespace inside braces is accepted. Unknown fields are configuration errors.
There is no generic template engine and no process-environment lookup.

Rendering happens once per turn before provider chat composition. The rendered
text remains in the base system instruction plane. The memory context rule
remains a separate system segment. The provider-visible user envelope is
unchanged and contains only its existing version, retrievedContext and message
fields.

The generic `You are a helpful AI assistant.` text remains fallback-only when
neither persistent/session nor configured global base instructions exist.

`provider_model` uses the actual execution provider plus selected profile id.
`model_capabilities` uses the profile input modalities and A008-owned
generation capability metadata. Project cwd is propagated into the local runtime
from CLI/ACP/EngineHost ownership rather than inferred from process.cwd() for
multi-project sessions.
