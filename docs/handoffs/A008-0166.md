resolver does not read that file. The KIE, OpenAI, OpenRouter, Groq, Gemini,
and OpenCode resolvers call `loadProviderSecrets` when those environment keys

launch MCP. The charter said to report any other unisolated host config for

session construction passes no MCP servers.
