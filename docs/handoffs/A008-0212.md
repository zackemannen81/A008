## Investigation findings

- Electron main imports Electron's `dialog` and can display native message boxes. Its BrowserWindow has context isolation and sandbox enabled, no preload is configured, and no IPC bridge was found in the Electron source.
- The GUI host runs separately in `src/gui-host/server.ts`. Electron can launch a bundled host, but also probes and reuses an already-running compatible host. Therefore a main-process dialog cannot be assumed to be present or reachable for every host request.
- Durable conversation storage in `A008_platform_conversations` has project/workspace IDs but no host-owned root/main-vs-parallel role. Conversation creation routes currently bind a conversation to a workspace.
- Existing authenticated principals establish client/device capabilities, not which durable conversation originated a user confirmation. Renderer state or an ordinary HTTP response cannot be accepted as proof of native Yes.
- No tests, builds or typechecks were run because this slice performed documentation/trust-boundary inspection only. `git diff --check` passed after local documentation edits.

## Remaining blocker

A008-0212 still needs to define and prove both (1) a durable, project-bound root/main role and (2) an authenticated out-of-band host-to-native-broker request/result channel that is unavailable to renderer and direct HTTP callers. The challenge must bind the exact action and target, expire, consume once, and fail closed when the trusted broker is unavailable. The implementation must explicitly address standalone and Electron-reused-host operation; an Electron dialog alone is not sufficient.

## Next step

Design the smallest broker transport compatible with supported local deployment modes, then implement it with adversarial tests for spoofing, wrong role/target, expiry, cancellation, replay and concurrent consumption. If the channel cannot be established without trusting renderer/HTTP claims, keep destructive actions paused and request a product-direction decision rather than weaken the requirement.
