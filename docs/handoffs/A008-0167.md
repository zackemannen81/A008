## Delivered

One bundled Platform page beside Memory, Tools and Help. It calls `GET /v3/info` through `createPlatformV3Client`. `available: false` is an explicit unavailable state and does not list conversations or start a run.

Resource calls use injected fetch and the existing credential adapter. The page does not keep a bearer token. A host `browser-pin` profile uses the PIN cookie and does not send an engine bearer. Without that profile, a device credential adapter is required; otherwise the page says platform resources require the existing host login. There is no anonymous V3 access.

The user picks a project already returned by `GET /v1/projects`, may create one V3 conversation, and may start one text run with the chat session's current model. No model keeps start disabled. Each start mints one `commandId` and Retry resends that same id, model, text and revision. The page does not auto-retry, replace the id, or cancel a run when the page or client closes. Events poll only while the page is active. Run status is text: queued, running, completed, cancelled, failed, `needs_reconciliation`, and `cancel_requested`.

V1 chat, the project sidebar, reset and model change are unchanged. No import, migration, tools, or approvals.

## Known limitations

- Text-only. No tools, durable approval, migration, import of saved chats, or public reconciliation.
- The page does not cancel runs. Closing it only stops polling.
- After a conflict or transport failure, Retry repeats the same command. A different payload needs a new start only once that attempt is no longer pending, failed, or in conflict.
- The bundled page does not ask for a device secret. A device credential has to be injected as the existing bearer adapter. The renderer does not store it.
- An engine capability token is not platform auth.
- The host proof is one GUI-host process and two client objects, not a second OS process. It uses the loopback provider, not a live product provider.
- Polling is a one-second event read while the page is active, not a push channel.
