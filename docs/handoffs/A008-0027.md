## What landed

Evidence-only lifecycle and retrieval intents on the in-memory knowledge engine (M6).

- `MemoryLifecycle` attaches to utterance, event, claim, and artifact-summary evidence. Bindings, transitions, entities, and artifact identity have no strength.
- Named processes `REINFORCE` / `WEAKEN` / `DECAY` / `REACTIVATE` record caller and reason. Decay may move evidence to `dormant`. It never makes a fact untrue and never writes state.
- Read path: `DEFINE` → `RETRIEVE` → `EXPAND` → `FILTER` → `COMPOSE` → `PROJECT`.
- Direct slot/entity/exact match ignores memory state. Associative expansion (depth 1) excludes dormant evidence with reason `associative_dormant`.
- `DEFINE` consumes temporal hints (`mentionsPast` / `currentOnly` / `mentionsFuture`). Closed intervals are reachable only under history intent.
- `retrievalScore` is ephemeral. Memory strength is a scoring term only for associative expansion.
- Tags discover; a tag miss does not exclude a direct slot match.
- `PROJECT` writes nothing and emits the §9.3 sectioned payload.

Full model §11 S1–S10 pass through this read path. A decay sweep leaves every direct-question answer unchanged.
