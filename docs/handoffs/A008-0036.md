## What landed

GUI terminal module for ADR 0019 D4/D6.

- `runShellCommand(command)` sends `POST /v1/shell` with JSON `{ command }`.
  Optional injected `fetch` fakes the host in tests. Default URL is `/v1/shell`
  so Vite's `/v1` proxy reaches the GUI host.
- Request uses `credentials: "omit"` and never sets `Authorization` or
  `NVIDIA_API_KEY`.
- The browser does not evaluate or spawn the command. No WebContainer, `eval`,
  `Function`, or `child_process`.
- Host result `{ stdout, stderr, exitCode, timedOut, truncated }` is parsed
  strictly and formatted to a string for A008-0035's composer.
- `TerminalPane` remains the stub export, class `a008-terminal`, no required
  props. `App` still renders `<TerminalPane />`.
