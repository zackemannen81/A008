# A008-0194 handoff

Completed 2026-09-28.

## Outcome

Two ADR-0055 GUI regressions were removed without reintroducing a global current-workspace owner.

- Memory inspection now binds explicitly to the selected durable `projectId`.
  `/v1/memory?projectId=...` resolves the matching project runtime through
  `ProjectRuntimeRegistry` and inspects that project's shared memory. Switching
  projects no longer reuses whichever legacy ACP bridge happened to be cached.
- Semantic/Budgets/Instructions now use host-owned runtime preferences through
  `/v1/runtime-preferences`. Read, save and reload do not start a chat, worktree
  or session process and remain available even when the selected project has no
  conversation yet.
- Existing legacy memory callers without `projectId` retain the previous ACP
  bridge path for compatibility.

No memory-engine, retrieval, session-process, worktree lifecycle or provider
behavior changed.

## Boundaries

through its existing bridge. This compatibility path is not used by the durable
Memory view.
