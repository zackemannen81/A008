accepted input; live snapshots contribute only a validated suffix. Outgoing text
is shown immediately and reconciled by run identity, including repeated text.

using an optional ephemeral liveRevision. Thought and answer update independently
as the host receives process activity. The 700 ms view refresh remains for run
lifecycle and reconnect fallback. Waits expire after 25 seconds, clean up on
disconnect and recheck authorization before delivery. Observation never owns or
cancels the run. Selection guards prevent cross-chat updates; overlapping
permission decisions share an in-flight request.
