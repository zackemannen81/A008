# Handoff — A008-0154 MCP health probe and isolated session lifecycle

Status: Complete
Date: 2026-09-22

## What changed

Saved stdio MCP servers can be probed without touching an open chat.
`POST /v1/mcp-servers/probe` spawns the saved command, performs MCP
initialize, `tools/list`, and catalog validation, then closes the process.
`GET /v1/mcp-servers/health` reports READY, FAILED, or RESTART REQUIRED.
RESTART REQUIRED means a still-open host session was constructed with a
different enabled catalog. Probe memory is process-local.

Each `ModelToolSession` has one execution id. Every MCP child receives
`A008_MCP_EXECUTION_ID` and a stable `A008_MCP_SERVER_SCOPE`. If the server's
own schema publishes a string `session` argument, the model-facing schema omits
it and every call uses the scope. Published domain containment combined with
`restore`, `state`, or `sessionName` is rejected before execution. The server
name is not inspected.

V2 session construction now receives the host catalog path, matching the
bundled bridge.
