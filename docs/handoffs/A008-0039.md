## The finding the operator should read

**The three ambient declaration files were dead.** Deleting all three left the
GUI typecheck green, because TypeScript walks up from `gui/` and resolves
`node:test` from the ROOT package's `node_modules/@types/node`. `tsc
--listFiles` confirms the root copy was in the program and the GUI's own
declaration was not.

That meant two things nobody had noticed:

1. The GUI package's typecheck depended on a sibling package's devDependency. A
   standalone `gui/` install would not have typechecked.
2. Full Node typings were in scope for renderer code. `gui/src/app.tsx` could
   have imported `node:child_process` and compiled. The boundary those three
   shim files were written to protect never existed.

`"types": []` plus including `test` makes the single declaration real. Verified:
adding `import { spawn } from "node:child_process"` to `gui/src/app.tsx` now
fails with TS2307, where before it compiled.

Cutting off the real typings surfaced 46 narrowing errors, because
`node:assert/strict` declares `ok` as `asserts value` and `equal` as
`asserts actual is T`, and the chat and session tests depend on both. The shared
declaration mirrors those two signatures. No test was weakened to make this
pass.

## Risks the operator should weigh before merging

1. **`node:fs`, `node:path`, and `node:url` are still declared program-wide**,
   because `gui/src/session/gui-session-client.test.ts` imports them and an
   ambient module declaration cannot be scoped to test files without a separate
   TypeScript project. Renderer code can still reach those three. Every other
   Node built-in is now blocked.
2. **`"types": []` is a real behavior change to the GUI typecheck.** Anything
   added later that expects ambient `@types/*` globals in `gui/` must now
   declare them explicitly. That is the intent, but it will surprise someone.
3. **Root `npm test` is slower**, since it now builds and runs both suites.
   `npm run test:core` is the fast path during core work.
4. **`test:core` content is byte-identical** to the previous `test` script; only
   its name changed. Anything scripted against `npm test` still works and now
   covers more.
