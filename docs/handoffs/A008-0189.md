## Delivered behavior

The worker and dialogue extractor share one model-item allowlist: `id`, optional
resolved `semanticAddress`, one `currentState` or `claim` string, and conditional
`history`/`provenance`. The outer envelope is `A008_memory_context_v2`.
Internal evidence IDs, labels, scores and scope remain available to A008 but
are absent from model items. Structured values become lossless JSON text.

Current state owns its address; otherwise the latest applicable claim is used.
Different addresses with equal values remain distinct. Raw assertions backing
selected claims are suppressed. Historical questions include prior states/claims;
closed timelines without HEAD use a qualified historical assertion. Contested
claims preserve competing assertions/attribution in optional provenance.
Known conversation-source locators are rendered without runtime control IDs.

Specific turn tags narrow associative domain-only spillover when narrower hits
exist. Exact address reads remain eligible. Budget omissions are reported and
an oversized first item is no longer forced into the envelope.

Internal identity/evidence mapping and existing write semantics remain intact.
The extractor is told to reinforce repeated equivalent knowledge, update changed
properties and retain independently new properties. Local SQLite tests verify
reuse, history, idempotency and restart. Retrieval alone does not reinforce.

## Boundaries and handoff

This does not clean existing duplicated database entries, add a general semantic
reranker, change provider APIs or implement ADR 0055's process architecture.
History/provenance selection follows the existing intent and retrieval signals;
unavailable sources or workspace attribution are not invented. Model extraction
quality remains model-dependent; local fixtures verify the contracts and runtime
identity behavior, not the quality of a live model's interpretation.

The six unrelated base failures remain open. Integration should account for the
v2 envelope in any external tooling that parses the old internal prompt shape.
Project brief, ADR index, memory model, system document and current status were
updated together. Necessity/scope review found only changes needed for the
approved minimal context and its identity/provenance semantics.

`CURRENT_TASK.md` restored from its template. Journal append is deferred to merge
as required by the workflow. Existing deletions of the three
`docs/A008-0187-*.txt` files were left untouched.
