avoids generic padding. Runtime does not manufacture fallback labels.

preserve the resolved baseline entity/attribute. Ambiguous targets must not be
guessed. No transcript duplication, alias system or state-owner change.

Actual use of a retrieved property in a recommendation is explicitly included
in reinforcement. Mere topical overlap or retrieval remains insufficient.

and does not use the dialogue continuity boundary, so it remains unchanged.
