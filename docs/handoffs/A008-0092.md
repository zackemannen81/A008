# A008-0092 Handoff

Status: Complete
Date: 2026-09-09
Owner: Codex

## Outcome

Standalone A008 sessions now survive brief mobile/browser WebSocket interruptions without creating a new chat session. The host sends protocol heartbeats, keeps a disconnected ACP session under a short in-memory lease, and accepts capability-bound `session/resume` reattachment.

The bundled GUI automatically retries an established connection with bounded backoff and resumes the same committed session when the lease is still valid. It clears session-scoped Allow all and does not replay interrupted prompts or controls.
## Defaults and boundary

- WebSocket heartbeat: 25 seconds. An unanswered prior ping closes the peer at the next heartbeat.
- Detached resume grace: 45 seconds.
- GUI reconnect delays: 0.5s, 1s, 2s, then 5s capped.
- Resume capability: random 32 bytes / 64 lowercase hex; renderer + host protocol only.
- Explicit close, lease expiry and host shutdown invalidate the capability.
- Page reload, cross-device and host-restart resume are not implemented.
