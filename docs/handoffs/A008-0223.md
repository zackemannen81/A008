## Observed input
Owner stopped a tool-using task that was stable for >200 calls but repeated discovery decisions and unchanged file reads. Previous reducer kept facts/actions but dropped chronological source ordering in the model-visible projection, omitted explicit next step, and forced a single raw tool round regardless of configured retention. Model was asked to "continue" with no guaranteed explicit history of the work.

## Implementation
- `src/core/task-workflow.ts`: one bounded tool-free planning response per new text-based work run, with strict schema validation and safe starter-plan fallback; image-bearing requests deliberately bypass preplanning so the first provider call retains the image.
- Model-facing document is appended on *every* provider request: original request, description, evidence-backed checklist, source-sorted completed action findings, verified facts and hypotheses, recent raw tool rounds, and explicit next action. All labels/observations are untrusted; no authority changes.
- Runtime-owned always-available `a008_update_workflow` tool changes checked milestones and next action only if referenced source IDs belong to saved tool rounds reporting success. No project-file changes or effect replays.
- Stored `RunContinuationRecovery.workflow` is bounded, revalidated and retained across process replacement. Model does not recreate prior plan when recovery contains it. Each tool round records its intended purpose, and fallback summaries preserve it.
- For product working-context sessions, use configured recent-raw window (default 8). Compact in groups rather than after every call, or sooner under route pressure. Non-workflow callers keep legacy cadence. Prior reducer fallback/replay protections untouched.

## Known limits and tradeoffs
- Planning is a new provider call for text-based working runs; it costs tokens and can fail, in which case a generic plan is used. User base instructions remain unchanged.
- Runtime checks that successful source evidence exists, not whether the cited observation semantically proves the entire milestone.
- Older compacted history remains model-summarized rather than verbatim; the complete durable source record is retained. The recent tail stays raw.
- The 8-round window trades some request size for fewer reducer calls; pressure and hard budgets remain enabled. Opaque-effect resume stays fail-closed.
